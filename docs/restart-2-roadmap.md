# Дорожная карта RESTART 2.0

1. Интеграционная проверка. Запустить все тесты и сборку. Сверить файлы медиа с базовым коммитом. Измерить сырой и gzip-размер ключевых модулей.
2. Закрытый стенд. Проверить параметры Supabase, SMTP и точные redirect URL. Провести реальный Auth с согласованным адресом. Проверить два аккаунта и перенос данных между устройствами.
3. Академия и школа. Проверить миграции на отдельной базе перед облачным пилотом. Затем завершить управление медиауроками и порядок перетаскивания. Назначение первого владельца — отдельная операция после согласия.
4. Расписание. Проверить параллельную запись на штатном PostgreSQL, затем добавить лист ожидания и подтверждённые каналы доставки.
5. Мобильное завершение. Проверить доступность в реальном браузере, установку на Samsung и сохранение управления после обновления. Персональный план устройства можно расширить синхронизацией после согласования правил её хранения.

Релиз требует результатов шагов 1–2 и уместных проверок из шагов 3–5. Черновой PR нужен для ревью интеграции.
