# Архитектура RESTART 2.0

Все рабочие ветки созданы от `cf69a6a`. Интегратор владеет общими файлами `app/ui.mjs`, `app/school.mjs`, `app/sw.js` и упаковкой пилота. Общие компоненты соединены только после проверки их входных и выходных данных.

| Направление | Ветка с префиксом work/restart-2- | Контракт |
| --- | --- | --- |
| Cloud | cloud | PKCE, текущий аккаунт, уведомления о результате Auth |
| Сайт | design | существующие URL, меню и шаблоны публичных страниц |
| Академия | academy | RLS и метаданные `restart_programs`, ревизия, модуль карточки |
| Бронирование | booking | транзакционный RPC, время UTC и IANA, локальный календарь |
| План | personalization | отдельное хранилище устройства, идентификаторы каталога |
| Дневник и прогресс | progress | производные от реальных записей, без изменения хранилища |
| Роли | admin | `school_role()` для полномочий, отдельная проверка владельца |
| Мобильная оболочка | mobile | доступность, навигация, состояние установки и офлайна |
| QA | security | проверка сохранности материалов и режима публичной сборки |
| Интеграция | integration | сборка всех проверенных компонентов |

Новый SQL: 007 — метаданные курса, 008 — место и часовой пояс занятия, 009 — роль владельца и управление ролями. При закрытом пилоте слой данных и клиент должны проверяться совместно.
