# RESTART 2.0 — инструкция для владельца

1. В Supabase откройте `Restart → restart-app → Authentication → Emails → SMTP Settings`. Проверьте, включён ли Custom SMTP. Если он выключен, уточните, является ли тестовый адрес участником команды. Сообщите только результат проверки.
2. Согласуйте закрытый HTTPS-адрес пилота и первый тест на вашем разрешённом адресе. После настройки стенда откройте ссылку в Chrome на Samsung и используйте тот же браузер для письма подтверждения.
3. После входа создайте тестовую цель и заметку без личных данных, завершите тестовую практику. На втором устройстве проверьте, что те же записи появились после обновления кабинета. Отдельный тестовый аккаунт понадобится, чтобы подтвердить изоляцию.

Подробности, в том числе проверка функции допуска без отправки письма, находятся в [инструкции закрытого пилота](restart-cloud-pilot.md).
