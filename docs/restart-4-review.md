## Сборка

Из корня репозитория выполните `python3 releases/navigation/build.py`, затем `node --test tests/*.test.cjs`. Для просмотра раздавайте корень любым статическим HTTP-сервером. Для теста пути GitHub Pages разместите копию в подпапке yoga-platform. Открывайте index.html через HTTP или HTTPS.

Главная, О RESTART, философия, кодекс, программа, путь, практики, дневник, прогресс и участие имеют отдельные HTML-адреса. Первая неделя и история практик также имеют отдельные адреса. Маршрут дня внутри первой недели сохраняется в адресе.

Локальные ключи данных 3.0 и студии сохранены. Браузер ограничивает доступ к локальным данным адресом сайта. Домен закрытого предпросмотра имеет собственные записи и не синхронизируется с GitHub Pages. Прогресс 3.0 на том же домене доступен в записях 4.0. Заявка демонстрационная.

## Проверки

- 10 автоматических тестов, включая совпадение контрольных сумм, комплект PWA, прямые маршруты и моделирование отсутствия сети для страниц в подпапке.
- В Chrome под /yoga-platform/ проверены отдельные страницы, кнопка «Назад», прямая ссылка и перенаправление старой ссылки на практику, работа таймера при открытии практики, два режима фильтрации каталога, три языка с сохранением выбора при переходах, 13 понятий и восемь карточек программы.
- Все семь дней открывались напрямую, по четыре задания. После перезагрузки отчёта сохранились 28 отметок и запись из дневника. В отчёте семь ссылок на дни.
- Тестовая установка и полный офлайн-сеанс на физическом Samsung отложены до закрытой публикации. Среда локального автоматического мобильного запуска не предоставила браузерному процессу необходимые разрешения.

## Закрытый предпросмотр после согласования

На текущем закрытом домене предпросмотра 3.0 разместить 4.0 в подпапке /v4/. В корне сохранить предпросмотр 3.0. Манифест и регистрация service worker в 4.0 используют относительные пути и область /v4/. Развёртывание возможно после разрешения владельца. Публичный GitHub Pages и активная PWA остаются на текущей версии.
