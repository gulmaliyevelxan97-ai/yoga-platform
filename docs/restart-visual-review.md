# Визуальное ревью RESTART

Главная сайта строится вокруг существующего портрета основателя. Карточки направлений используют реальные материалы каталога и ведут к действиям. В кабинете золотой выделяет основные действия, а голубой обозначает клавиатурный фокус. Светлая тема использует самостоятельную палитру. Достижения показаны только после выполнения условий.

Проверки релиза включают русский, азербайджанский и английский языки, размеры 360–430 px, обе цветовые схемы, клавиатуру и режим уменьшенного движения. Для курсов, записей и управления нужны тестовые данные и роли закрытого стенда. Проверка в Chromium не заменяет проверку Samsung.
