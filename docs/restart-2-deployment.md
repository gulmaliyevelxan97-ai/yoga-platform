# Сборка и закрытое развёртывание

Публичный сайт и `main` существуют отдельно. В интеграционной ветке запустите Node-тесты и проверочную сборку из [описания тестов](restart-2-testing.md). Установите фактический Project URL и publishable key в окружении закрытого билда. Запустите `npm run build:pilot`. Для повторной сборки укажите новый каталог через `RESTART_PILOT_OUTPUT`.

Локально кабинет доступен по `http://localhost:4173/app/` после запуска сервера из [инструкции пилота](restart-cloud-pilot.md). Для Samsung необходим согласованный закрытый HTTPS-хост и точный URL возврата. Весь набор миграций для 2.0 сначала проверяется в отдельной тестовой базе. На `restart-app` уже выполнены первые три. Для последующих применений сверяйте серверную историю и текущую схему.

Для клиентского отката используйте предыдущий проверенный артефакт. Восстановление базы и любые действия, меняющие пользовательские данные, требуют отдельного решения.
