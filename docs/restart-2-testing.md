# Проверки RESTART 2.0

```sh
npm ci
npm test
npm run build:pilot -- --verify
npm audit
```

Тесты Node покрывают состояние кабинета, реальные идентификаторы видео, локализацию, PKCE с SDK и подменёнными ответами, упаковку PWA, PGlite-политики и SQL-функции, импорт, курс, роли, посещаемость и бронирование. Тест сохранности медиа требует истории Git с базовым коммитом.

Отдельно запускаются `tests/mobile-offline.py` с локальным адресом и `scripts/test-booking-race.py` со штатными инструментами PostgreSQL. Скрипт бронирования создаёт временный кластер. Проверка Samsung проводится на устройстве с закрытым HTTPS-адресом. Фактические результаты фиксируются в отчёте, независимо от наличия сценария в репозитории.

Перед закрытым пилотом пройти сценарии регистрации, письма, восстановления и синхронизации из [инструкции пилота](restart-cloud-pilot.md).

## Дизайн и навигация

Проверяйте системную, светлую и тёмную тему на одной и той же странице. Переключение должно переживать перезагрузку и не менять язык или пользовательские данные. Для мобильной панели проверяйте возврат назад, прямые ссылки и отсутствие перекрытия контента. Сравнивайте `assets/` с базой `1d98ade` и проверяйте пути изображений в собранном пилоте. В офлайне убедитесь, что дневник сохраняет локальные записи, а действия, требующие сервера, имеют понятные состояния.
