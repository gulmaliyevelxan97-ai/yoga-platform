# Навигация RESTART

| Маршрут приложения | Назначение |
| --- | --- |
| `#today` | Практика дня и быстрые действия |
| `#practices` | Каталог и запуск практики |
| `#academy` | Академия, доступные программы и уроки |
| `#path` | Активность, тренды, достижения, цели и персональный план |
| `#profile` | Настройки, аккаунт и доступ к наставнику |
| `#journal` | Личные записи |
| `#schedule` | Календарь занятий |
| `#classes` | Записи и история |
| `#staff` | Управление школой по серверной роли |
| `#mentor` | Профиль наставника |

Публичные страницы остаются отдельными URL. `index.html` ведёт к практикам, программе, разделам школы и основателя. Академия и расписание открываются внутри приложения. Hash-маршруты кабинета сохраняют навигацию браузера и прямые ссылки.
