# RESTART · Telegram-бот

Бот открывает разделы действующего сайта RESTART. Для программы на 56 дней предусмотрены постоянный идентификатор, длительность, четыре направления и ссылка на анонс. После подключения сервиса участников он сможет получать дату начала, задания по дням и состояние выполнения. Сейчас бот показывает недельный план сайта и анонс. Профиль и история по-прежнему хранятся в браузере сайта, а бот хранит только настройки Telegram: ID личного чата, язык, часовой пояс, время и согласие на напоминания.

## Проверка без токена

Из папки `telegram-bot` запустите `npm test` с Node.js 24 или новее. Тесты используют изолированную SQLite и имитацию ответов Telegram. Сторонние npm-зависимости не требуются.

## Запуск созданного бота

1. Разместите папку `telegram-bot` на машине с Node.js 24+, исходящим HTTPS к `api.telegram.org` и диском, который сохраняется между перезапусками. Для надёжных напоминаний процесс должен работать постоянно.
2. Передайте `TELEGRAM_BOT_TOKEN` через секреты хостинга или менеджера процессов. Для локального запуска можно создать файл `.env` только в папке бота, задать владельцу права чтения и записи (`chmod 600 .env` в Linux/macOS) и вписать токен редактором. Пустой шаблон есть в `.env.example`. Не копируйте токен в чат, Git, скриншоты, командную строку или логи. Если токен раскрыт, замените его через BotFather.
3. Для постоянного запуска задайте `RESTART_BOT_DB` абсолютным путём к SQLite в приватном каталоге вне публичных файлов сайта. По умолчанию локальный путь — `./data/restart.sqlite`. Начальный часовой пояс — `Asia/Baku`. Для другого пояса задайте `RESTART_BOT_TIMEZONE`. При наличии официальной страницы поддержки передайте её HTTPS-ссылку через `RESTART_TEAM_URL`. Пока используется Instagram основателя.
4. Запустите `npm start` в единственном экземпляре. Бот использует long polling, поэтому публичный webhook и входящий HTTP-порт не нужны. Если webhook уже подключён, запуск остановится. Смена существующей интеграции требует отдельного согласования.
5. Откройте личный чат с ботом по его имени и нажмите «Запустить» или отправьте `/start`. Для контрольного напоминания укажите время на несколько минут вперёд через `/time HH:MM`, проверьте часовой пояс и нажмите «Включить напоминания». После теста можно отправить `/stop`.

Бот поддерживает `/start`, `/language`, `/reminders`, `/time HH:MM`, `/timezone Asia/Baku` и `/stop`. Согласие требуется отдельно после выбора времени. Доставка идёт один раз в день в выбранном часовом поясе. После простоя окно догоняющей отправки составляет 10 минут. Заблокированные чаты отключаются автоматически. При неопределённом ответе от Telegram повторная отправка в тот же день не выполняется, чтобы избежать дублей.

## Будущие задания и согласие

Для сообщений 56-дневной программы необходимы утверждённый календарь заданий, подтверждённая привязка Telegram к записи участника и отдельное согласие на этот тип сообщений. Напоминания о практике не дают согласия на программные или рекламные сообщения. Цены, платежи и условия участия не меняются.

Источник по Telegram Bot API: https://core.telegram.org/bots/api
