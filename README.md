# Yoga Space

Международная онлайн-студия Elxan Gülmalıyev. Сайт работает как статический проект GitHub Pages на HTML, CSS и JavaScript. На клиенте отсутствуют сторонние зависимости времени выполнения.

[Опубликованная студия](https://gulmaliyevelxan97-ai.github.io/yoga-platform/) · [Основатель](https://gulmaliyevelxan97-ai.github.io/yoga-platform/#founder)

## Локальная разработка

Запустите `python -m http.server 8000` из корня проекта. Откройте страницу на localhost. Для проверки файлов, маршрутов каталога, переведённых строк и согласованности версий ресурсов выполните `node --test tests/*.test.cjs`.

Текущие исходники JS/CSS находятся в `releases/stages-4-5/`. Старые файлы в корне требуются для кешированных страниц предыдущего выпуска. При несовместимом обновлении создавайте новый каталог ресурсов и переключайте все ссылки в HTML одним коммитом.

- `languages.js` содержит переводы и инструкции к практикам. Порядок переводов — русский, азербайджанский, английский.
- `studio.js` связывает преподавателей, авторские занятия, карточки видео, локальные черновики и страницу основателя.
- `pathways.js` содержит программы, персональные планы, раздел доступа и дополнения к профилю.
- `app.js` отвечает за таймер, маршруты, смену языка и историю. Идентификаторы практик стабильны.
- `index.html` содержит первоначальную русскую версию главной, основных фотографий и биографии. Сохраняйте её при изменениях переводов. Для каждого изменённого JS/CSS учитывайте первые 12 символов SHA-256 в ссылке на ресурс. Проверьте прямые ссылки и повторный вход после выпуска.
- `assets/` содержит локальные файлы. Изображения профиля и практик отображаются с исходными пропорциями.

Программы с таймером можно проходить после выбора урока на странице программы. Архив прежних самостоятельных занятий остаётся в профиле. Ручная отметка недельного плана обозначает выполнение пункта плана. Минуты в статистике начисляет таймер завершённой практики.

## Публикация и откат

Перед выпуском сохраните ветку от рабочей main. Проверьте кандидата в отдельной ветке. Обновляйте main только прямым потомком проверенной версии. После успешного развёртывания сравните файлы с опубликованными, проверьте прямой вход по #founder и #course/yoga, локальную историю и переключение языков. При проблемах используйте обратный коммит с деревом резервной версии. Для этапов 4–5 исходная ветка — backup/before-stages-4-5-20261118.

[Проект серверной части](docs/backend.md) · [Источники для страницы основателя](docs/founder-sources.md)

Для браузерной регрессии передайте изолированную страницу Playwright и базовый URL в `verifyStudio(page, baseURL)` из `tests/browser-smoke.cjs`. Проверка создаёт тестовый локальный прогресс, проходит два модуля с управляемыми часами, восстанавливает таймер и проверяет демозаявку. Запускайте её в новом браузерном контексте.
